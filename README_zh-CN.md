## 📖 1. 游戏简介
欢迎回到海上丝绸之路！PortMasters 2 把这个系列带进了联机时代。两位船长共享同一段航程，始终处于同一回合、同一阶段。你们既比拼声望，也在路上互通有无：货物、金币、情报都可以交易。每回合从「航海家的罗盘」抽福缘，向牙行打探消息，给旗舰装上船舶模块，并在工资、维护费和税收的压力下撑过整段航程（轻松模式 8 个回合，高难模式 16 个回合）。最后声望更高的人就是赢家。

相比 PortMasters 1 的新内容：
- 🌐 双人在线对局，带账号系统、游戏大厅、邀请、聊天和断线重连。
- 🤝 互市阶段，可以和伙伴自由交换货物与金币。
- 🧭 福缘：每回合罗盘给每位船长各发 4 张随机增益，自己挑一张锁定，对方手牌和你不一样。
- 🗣️ 牙行密语：花点金币买情报，每条线索都会在当回合变成一张稳赚的订单。
- 🔧 船舶模块：抽取并安装最多 3 个，从走私暗舱到超载引擎都有。
- 👀 观战窗口，破产之后还能看着伙伴把航程跑完。
- 🌍 整个界面有英文（默认）和简体中文两套，点 🌐 按钮随时切换。
- ⚖️ 两种难度模式。轻松模式让航程停留在基础货物之内，玩起来更从容；高难模式则通过丝路特许开放完整贸易。由发出邀请的船长选择难度，另一位确认后开始，且每一局默认都是轻松模式。
- 🗺️ 丝路特许：第 6 程「市舶新政」与第 10 程「万国通商」分两批扩展贸易网络，新增 4 种原料、4 种成品、4 类工匠、4 座港口（共 9 座）、6 张福缘、6 个船舶模块和 4 种季风（共 8 种）。第 1-5 程的玩法与之前完全一致。这套分批解锁正是高难模式的体验，高难模式共 16 个回合；在轻松模式下，整段 8 个回合的航程会全程停留在基础内容上，这些扩展不会出现。

## 🛠️ 2. 安装与运行

### ✅ 前置要求
- 运行服务器的机器装有 Python 3.10 或更新版本。
- 只依赖一个库：`websockets`（见 `requirements.txt`）。
- Windows、macOS、Linux 都可以。玩家这边只需要一个现代浏览器。

### 🚀 运行步骤
1. 下载或克隆项目文件夹。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 启动服务器：
   ```bash
   python server.py
   ```
4. 每位玩家在浏览器里打开 `http://localhost:8080`（局域网内用主机地址加 8080 端口），注册账号并登录。
5. 在大厅里邀请一位在线玩家。为本局选择难度（默认轻松），等对方看过说明并接受后，共享航程就开始了。🌊

> 💡 想跨互联网联机：网页和 WebSocket 共用 8080 这一个端口，所以一条 `ngrok http 8080` 隧道就能带起整个游戏，https 和 wss 都不用操心。

## 🎮 3. 游戏机制

一局在轻松模式下共 **8 段航程**（回合），在高难模式下共 **16 段**，每段航程走完 **8 个阶段**。每个阶段都要两位船长都确认了才往下走。

| 阶段 | 描述 |
|:---|:---|
| **⚓ 启航** | 确认开始本回合。从第 2 程起，这一页还会回顾上一程的收支。 |
| **🧭 福缘** | 罗盘从 8 张福缘里随机发给你 4 张，伙伴拿到的是另一手牌。锁定一张，只在本回合生效。 |
| **🛒 采购** | 从进货卡里买原料和成品（轻松模式 5 张；高难模式在第 6 程首批解锁后增至 8 张，第 10 程第二批解锁后增至 11 张）。页面顶部的「牙行密语」面板出售未来需求的情报。 |
| **🤝 互市** | 和伙伴做买卖。挂出「我出这个，换你那个」的订单，对方一点接受就成交。 |
| **👥 工匠** | 雇人、辞人、派生产任务。材料在派任务的那一刻就扣掉了。 |
| **📦 贸易** | 用库存交付港口订单。买到的线索会在这里变成带 🗣️ 标记的保底订单。 |
| **🔧 结算** | 产出入库、工资自动扣掉，然后你手动支付 15 金币维护费。付不起，船队就破产了。 |
| **🚢 船坞** | 想升船就升（0 到 3 级），想抽模块就抽，然后结束这一程。 |

### ⚖️ 难度模式
每一局都会在两种难度之一下进行，并且除非有人特意改动，游戏始终从「轻松」开始。

- **🌱 轻松**：共 8 个回合，整段航程都停留在基础货物之内。你将经营麻布、丝绸、茶叶这三种起始原料，制作四种入门成品，并从前三类工匠中招募帮手，与之相关的福缘、船舶模块、港口和季风也都限定在这套基础内容之内。棋盘始终不会过度拥挤，你有充足的余裕慢慢熟悉每个回合的节奏。
- **🔥 高难**：共 16 个回合，开放完整的海上贸易，玩法与下文「丝路特许」的分批解锁完全一致。前五程仍像轻松模式一样从容，随后其余原料、成品、海外港口、专精工匠，以及更丰富的福缘、模块与季风会逐步加入。需要打理的事务多得多，对舱位与金币的竞争也激烈许多。

难度在航程开始前就已商定。你邀请另一位船长时选择难度，对方会看到一段简短说明，了解它会改变什么之后再确认，因此双方始终在同一难度下经营同一段航程，重新开局也会沿用这个难度。

### 📦 资源类型
原材料：
- `麻布` 🧶，做普通衣服的日常布料。
- `丝绸` 👘，高档货背后的好料子。
- `茶叶` 🍵，香囊的香气来源。
- `瓷土` 🧱，烧制青瓷器的好原料`（市舶新政，第6程起）`。
- `铜矿` ⛏️，可以打造铜镜与器具`（市舶新政，第6程起）`。
- `香料` 🌶️，来自南洋的芬芳货物`（万国通商，第10程起）`。
- `珍珠` 🦪，来自南方海域的珍宝`（万国通商，第10程起）`。

成品：
- `麻衣` 👔：用 2 麻布（织女制作）。基准产值 15，市价大约 30~42。
- `布衣` 👕：用 2 麻布加 1 丝绸（织女制作）。基准产值 35，市价大约 50~65。
- `绫罗绸缎` 👗：用 3 丝绸（只有纺织大师能做）。基准产值 60，市价大约 70~90。
- `香囊` 🌸：用 1 丝绸加 2 茶叶（只有香囊师能做）。基准产值 80，市价大约 95~120。
- `紫铜镜` 🪞：用 3 铜矿（铜匠制作）。基准产值 45，市价大约 55~72`（市舶新政，第6程起）`。
- `青瓷器` 🏺：用 3 瓷土（陶匠制作）。基准产值 65，市价大约 78~100`（市舶新政，第6程起）`。
- `蕃香脂` 🧴：用 2 香料加 1 丝绸（只有香料师能做）。基准产值 85，市价大约 100~130`（万国通商，第10程起）`。
- `珠链` 📿：用 2 珍珠加 1 丝绸（只有珠宝匠能做）。基准产值 105，市价大约 125~160`（万国通商，第10程起）`。

- **陶匠** 🏺 制作青瓷器。工资每回合 14 金币`（市舶新政，第6程起）`。

### 💰 税收与财务
- **增值税**：成品利润的 5% 左右，交付时自动扣。
- **所得税**：回合净利润的 10% 左右（拿了免税令是 5%），回合结束时自动扣。
- **运费**：每件货 2 金币，每升一级船便宜 5 金币，福缘还能再减，但最低 5 金币。
- **维护费**：每回合固定 15 金币（个别模块会加价），在结算阶段手动支付。付不起，这局就到此为止。

### 🌐 联机机制
- **账号**：用户名加密码。密码加盐哈希后存在 `users.json` 里。
- **邀请**：在大厅里每分钟只能发一次，60 秒没人理会自动失效。发出邀请时你还会为本局选择难度，对方在邀请窗口确认后航程才开始。
- **同步**：两位船长永远在同一回合、同一阶段。底部「双方就绪 n / 2」显示谁已确认。破产玩家自动算作就绪，绝不会拖住对方。
- **破产与观战**：破产的船长留在结算页，可以打开实时的 👀 观战窗口看伙伴继续玩。
- **断线重连**：会话保存在服务器上，重新登录就能接着玩。只有两个人都离线了，会话才会被回收。
- **重新开局**：两边的游戏都结束之后，任何一方都可以重置开新局。

## 💡 5. 策略建议
1. 现金永远排第一。工资和维护费每回合都要交，左边那个「本回合应付款项」已经替你算好了账。
2. 密语就是稳赚的买卖。每条线索都会变成对应货品、对应港口的真订单。装上牙行网络之后，情报几乎等于白送。
3. 能换就别买。伙伴面板把对方缺什么、囤什么写得明明白白，一笔好交换比市场价划算。
4. 利润在成品上。一个香囊能卖 95~120 金币，倒卖原料只能挣个零头。就是别忘了增值税。
5. 升船要趁早。运费折扣交付得越多省得越多，建议中盘前升到 1 级或 2 级。
6. 福缘跟着计划走：要大采购就拿商贾魅力，要爆产能就拿匠人灵感，快撑不住了就拿紧急钱庄保命。

## 🏆 6. 游戏终局与评级

打完整段航程（轻松模式 8 段，高难模式 16 段），每位船长按**声望**拿到最终评级。声望就是历次交付订单净利润的累计。

高难模式 16 段航程赚到的声望远多于轻松模式的 8 段，因此两种难度各有自己的门槛。

| 称号 | 轻松声望 | 高难声望 |
|:---|:---|:---|
| 👑 丝绸之路霸主 | ≥ 1200 | ≥ 6000 |
| 🏆 海上贸易大亨 | ≥ 800 | ≥ 4000 |
| ⭐ 成功商人 | ≥ 600 | ≥ 3000 |
| 👍 合格商人 | ≥ 400 | ≥ 2000 |
| 🌊 新手商人 | < 400 | < 2000 |

## 🛡️ 7. 故障排除
- **「端口 8080 被占用」**：有别的程序占着这个端口。关掉它，或者改一下 `server.py` 里的端口号。
- **「该账号已在其他设备登录」**：一个账号同时只能有一条连接，先把另一个标签页或设备关掉。
- **按钮点了没反应**：十有八九是在等伙伴确认。看看底部的「双方就绪 n / 2」，再用 💬 催一催。
- **伙伴掉线了**：会话在服务器上好好的，对方重新登录就行。聊天和交易会等到那时候再恢复。
- **服务器重启了**：账号还在 `users.json` 里，但进行中的航程存在内存里，没了就是没了，重新开一局吧。
- **跨互联网连不上**：用一条隧道（`ngrok http 8080`）把这个端口穿出去，让网页和 WebSocket 走同一个 https 来源。
