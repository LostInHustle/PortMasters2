## 📖 1. 游戏简介

欢迎回到海上丝绸之路！PortMasters 2 把这个系列带进了联机时代。两到五位船长共享同一段航程，始终处于同一回合、同一阶段。你们既比拼声望，也在路上互通有无：货物、金币、情报都可以交易。每回合从「航海家的罗盘」抽福缘，向牙行打探消息，给旗舰装上船舶模块，并在工资、维护费和税收的压力下撑过整段航程（轻松 8 个回合、标准 12 个回合、高难 16 个回合）。最后声望更高的人就是赢家。

相比 PortMasters 1 的新内容：

- 🌐 二至五人在线对局，带账号系统、游戏大厅、邀请、开放房间、聊天和断线重连。
- 🤝 互市阶段，可以和房间里的其他船长自由交换货物与金币。订单既可以公开发给全房间，也可以定向发给某一位船长，这时只有对方看得到、也只有对方能接受。
- 🧭 福缘：每回合罗盘给每位船长各发 4 张随机增益，自己挑一张锁定，每位船长拿到的手牌都不一样。
- 🗣️ 牙行密语：花点金币买情报，每条线索都会在当回合变成一张稳赚的订单。
- 🔧 船舶模块：抽取并安装最多 3 个，从走私暗舱到超载引擎都有。
- 👑 皇命金单：航程行进到特定节点时，贸易阶段会出现一张钦定贡令，报酬远高于普通订单。全程最后一张会被特别标记出来。
- 👀 观战窗口，破产之后还能看着其他船长把航程跑完。平时也可以随时点右侧同行名单里的任意一位船长打开它，谈交易之前先看清楚对方缺什么。
- 🔔 船队发生的每件事都会弹出提示，每条都能单独关闭；同时来好几条时还可以一键全部清除。
- 🌍 整个界面有英文（默认）和简体中文两套，点 🌐 按钮随时切换。
- ⚖️ 三档难度构成阶梯。轻松（8 回合）让航程停留在基础货物之内，玩起来更从容；标准（12 回合）以更紧凑的节奏开放完整贸易，且没有暗通海盗的牙行；高难（16 回合）是完整挑战，并开启可疑牙行机制。由发出邀请或开设房间的船长选择难度，且每一局默认都是轻松模式。
- 🗺️ 丝路特许：贸易网络分两批扩展，先「市舶新政」、后「万国通商」，新增 4 种原料、4 种成品、4 类工匠、4 座港口（共 9 座）、6 张福缘、6 个船舶模块和 4 种季风（共 8 种）。两批解锁在标准模式于第 4、8 程到来，在高难模式于第 6、10 程到来；轻松模式则全程停留在基础内容上，这些扩展不会出现。

## 🛠️ 2. 安装与运行

### ✅ 前置要求

- 运行服务器的机器装有 Python 3.10 或更新版本。
- 只依赖一个库：`websockets`（见 `requirements.txt`）。
- Windows、macOS、Linux 都可以。玩家这边只需要一个现代浏览器。

### 🚀 运行步骤

1. 下载或克隆项目文件夹。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 启动服务器：
   ```bash
   python server.py
   ```
4. 每位玩家在浏览器里打开 `http://localhost:8080`（局域网内用主机地址加 8080 端口），注册账号并登录。
5. 在大厅里邀请一位在线玩家，或开设一个 2 到 5 人的房间等其他船长加入。为本局选择难度（默认轻松），确认之后共享航程就开始了。🌊

> 💡 整个游戏就是一个 Python 文件加一个 HTML 文件，不需要构建，也没有打包工具挡在中间，这正是这一版好上手的原因。

### ⚙️ 服务器会读取的环境变量

两个都是可选的。不设置的话，行为和以前完全一样。

| 变量              | 作用                                                         |
| :---------------- | :----------------------------------------------------------- |
| `PORT`            | 监听端口，默认 8080。托管平台会自己指定，交给它设置即可。    |
| `USERS_FILE_PATH` | 账号数据的存放位置，默认是 `server.py` 旁边的 `users.json`。 |

## ☁️ 3. 跨互联网联机

### 🔌 方案 A：隧道，适合今晚就想开一局

网页和 WebSocket 共用同一个端口，所以一条隧道就能带起整个游戏，https 与 wss 都由它处理：

```bash
ngrok http 8080
```

把它打印出来的地址发给朋友就行，别的都不用配。隧道关掉就没了，所以这个方案适合临时开一局。

### 🚂 方案 B：Railway，适合让它一直在线

仓库里的 `railway.json` 已经把 Railway 需要知道的都写好了，部署基本上就是点几下：

1. 把仓库推送到 GitHub。
2. 在 Railway 里新建项目，选择 **Deploy from GitHub repo**，然后选中该仓库。
3. Railway 会读取 `railway.json`，按 `requirements.txt` 装好 `websockets`，再启动 `server.py`。它通过 `PORT` 变量分配端口，服务器会自己读取。
4. 在 **Settings** 里打开 **Networking**，点 **Generate Domain**。这个公开地址就是游戏本体，发给朋友即可。

由于网页和 WebSocket 都在这一个域名下，不需要再配第二个地址，也不会遇到混合内容的问题。

**让账号在多次部署之间保留下来。** Railway 每次部署都会重建容器并清空文件系统，所以放在脚本旁边的账号文件会连同已注册的船长一起消失。想保留就这样做：

1. 给该服务添加一个 **Volume**，挂载到 `/data`。
2. 添加变量 `USERS_FILE_PATH`，值填 `/data/users.json`。

这样账号就存在卷上，重新部署也不会丢。进行中的航程按设计只存在内存里，进程一重启就会结束，所以最好挑没人在航程中的时候部署。

## 🎮 4. 游戏机制

一局在轻松模式下共 **8 段航程**（回合），标准模式 **12 段**，高难模式 **16 段**，每段航程走完 **8 个阶段**。每个阶段都要所有船长都确认了才往下走。

| 阶段        | 描述                                                                                                                                                      |
| :---------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **⚓ 启航** | 确认开始本回合。从第 2 程起，这一页还会回顾上一程的收支。                                                                                                 |
| **🧭 福缘** | 罗盘从 8 张福缘里随机发给你 4 张，每位船长拿到的手牌都不同。锁定一张，只在本回合生效。                                                                    |
| **🛒 采购** | 从进货卡里买原料和成品（轻松模式 5 张；标准与高难模式在 Tier 1 解锁后增至 8 张、Tier 2 解锁后增至 11 张）。页面顶部的「牙行密语」面板出售未来需求的情报。 |
| **🤝 互市** | 和房间里的其他船长做买卖。挂出「我出这个，换你那个」的订单，任意一方接受即成交。可以公开发给全房间，也可以定向发给某一位船长。                            |
| **👥 工匠** | 雇人、辞人、派生产任务。材料在派任务的那一刻就扣掉了。                                                                                                    |
| **📦 贸易** | 用库存交付港口订单。买到的线索会在这里变成带 🗣️ 标记的保底订单；到了特定节点还会出现一张 👑 皇命金单，抵得上好几张普通订单。                              |
| **🔧 结算** | 产出入库、工资自动扣掉，然后你手动支付 15 金币维护费。付不起，船队就破产了。                                                                              |
| **🚢 船坞** | 想升船就升（0 到 3 级），想抽模块就抽，然后结束这一程。                                                                                                   |

### ⚖️ 难度模式

每一局会在三档难度之一下进行，构成由易到难的阶梯，并且除非有人特意改动，游戏始终从「轻松」开始。

- **🌱 轻松**：共 8 个回合，整段航程都停留在基础货物之内。你将经营麻布、丝绸、茶叶这三种起始原料，制作四种入门成品，并从前三类工匠中招募帮手，与之相关的福缘、船舶模块、港口和季风也都限定在这套基础内容之内。棋盘始终不会过度拥挤，你有充足的余裕慢慢熟悉每个回合的节奏。
- **⚖️ 标准**：共 12 个回合，是轻松与高难之间的中间一档，同样开放完整的海上贸易，但没有暗通海盗的牙行。丝路特许在第 4 程引入 Tier 1、第 8 程引入 Tier 2，让你以比高难更紧凑的节奏体验完整的货物、港口与工匠，海盗威胁也比轻松更明显。适合已熟悉基础、想要更多挑战，又不想一上来就投入高难长局的船长。
- **🔥 高难**：共 16 个回合，开放完整的海上贸易，玩法与下文「丝路特许」的分批解锁完全一致。前五程仍像轻松模式一样从容，随后其余原料、成品、海外港口、专精工匠，以及更丰富的福缘、模块与季风会逐步加入。需要打理的事务多得多，对舱位与金币的竞争也激烈许多。海盗洗劫与雇佣护航的费用都按当前财富浮动，且在高难航路上部分牙行会暗通海盗：购买密语时可能被走漏行踪、抬高海盗袭扰概率，让结算阶段是否雇佣护航成为真正的取舍。

难度在航程开始前就已商定。由发出邀请或开设房间的船长选择难度，受邀者会看到一段简短说明，了解它会改变什么之后再确认，因此所有船长始终在同一难度下经营同一段航程，重新开局也会沿用这个难度。

### 🗺️ 两批扩展分别在什么时候到来

下面标注了 `（市舶新政）` 或 `（万国通商）` 的内容，会在对应的那一批扩展到来时加入游戏，而两批扩展到来的时间取决于难度：

| 难度    | 市舶新政 | 万国通商 |
| :------ | :------- | :------- |
| 🌱 轻松 | 不会到来 | 不会到来 |
| ⚖️ 标准 | 第 4 程  | 第 8 程  |
| 🔥 高难 | 第 6 程  | 第 10 程 |

轻松模式从第一程到最后一程都停留在基础内容上，所以下面标注过的东西一样都不会出现。

### 📦 资源类型

原材料：

- `麻布` 🧶，做普通衣服的日常布料。
- `丝绸` 👘，高档货背后的好料子。
- `茶叶` 🍵，香囊的香气来源。
- `瓷土` 🧱，烧制青瓷器的好原料`（市舶新政）`。
- `铜矿` ⛏️，可以打造铜镜与器具`（市舶新政）`。
- `香料` 🌶️，来自南洋的芬芳货物`（万国通商）`。
- `珍珠` 🦪，来自南方海域的珍宝`（万国通商）`。

成品：

- `麻衣` 👔：用 2 麻布（织女制作）。基准产值 15，市价大约 30~42。
- `布衣` 👕：用 2 麻布加 1 丝绸（织女制作）。基准产值 35，市价大约 50~65。
- `绫罗绸缎` 👗：用 3 丝绸（只有纺织大师能做）。基准产值 60，市价大约 70~90。
- `香囊` 🌸：用 1 丝绸加 2 茶叶（只有香囊师能做）。基准产值 80，市价大约 95~120。
- `紫铜镜` 🪞：用 3 铜矿（铜匠制作）。基准产值 45，市价大约 55~72`（市舶新政）`。
- `青瓷器` 🏺：用 3 瓷土（陶匠制作）。基准产值 65，市价大约 78~100`（市舶新政）`。
- `蕃香脂` 🧴：用 2 香料加 1 丝绸（只有香料师能做）。基准产值 85，市价大约 100~130`（万国通商）`。
- `珠链` 📿：用 2 珍珠加 1 丝绸（只有珠宝匠能做）。基准产值 105，市价大约 125~160`（万国通商）`。

### 💰 税收与财务

- **增值税**：成品利润的 5% 左右，交付时自动扣。
- **所得税**：回合净利润的 10% 左右（拿了免税令是 5%），回合结束时自动扣。
- **运费**：每件货 2 金币，每升一级船便宜 5 金币，福缘还能再减，但只算到这一步的话最低是 5 金币。船舶模块可以突破这个下限，一直减到 0：散货索具每件货再省 1 金币，超载引擎从总额里减 5 金币，丝路垄断则让丝绸完全免运费。贸易界面上每张订单显示的都是你这支船队实际会被扣掉的金额，上面这些全都已经算进去了，看到多少就是扣多少。
- **维护费**：每回合固定 15 金币（个别模块会加价），在结算阶段手动支付。付不起，这局就到此为止。

### 🌐 联机机制

- **账号**：用户名加密码。密码加盐哈希后存在 `users.json` 里。
- **邀请与房间**：大厅邀请每分钟只能发一次，60 秒没人理会自动失效；也可以开设一个 2 到 5 人的房间，让其他船长自由加入。两种方式都会先定下难度，受邀者在邀请窗口确认后航程才开始。
- **同步**：所有船长永远在同一回合、同一阶段。底部「全员就绪 n / N」显示已确认的人数。破产玩家自动算作就绪，绝不会拖住其他人。
- **互市**：订单默认对全房间公开，除作者本人外谁都能接。改成定向发给某一位船长后，就只有对方看得到，已经在聊天里谈好的交易不会被第三个人截走。
- **破产与观战**：破产的船长留在结算页，可以打开实时的 👀 观战窗口看其他任意一位船长继续玩。平时点右侧同行名单里的任意一位船长也能打开同一个窗口，谈交易前先摸清对方的底细。窗口会实时更新，也不会打断你正在看的内容。
- **断线重连**：会话保存在服务器上，登录成功后浏览器里还会留下一个凭证，所以刷新页面或稍后回来都能直接接着玩，不用重新输密码。只有所有船长都离线并超过一段宽限时间，航程才会被回收。
- **重新开局**：所有人的游戏都结束之后，任何一位船长都可以重置开新局。

## 💡 6. 策略建议

1. 现金永远排第一。工资和维护费每回合都要交，左边那个「本回合应付款项」已经替你算好了账。
2. 密语就是稳赚的买卖。每条线索都会变成对应货品、对应港口的真订单。装上牙行网络之后，情报几乎等于白送。
3. 能换就别买。船长面板把其他船长缺什么、囤什么写得明明白白，一笔好交换比市场价划算。
4. 利润在成品上。一个香囊能卖 95~120 金币，倒卖原料只能挣个零头。就是别忘了增值税。
5. 升船要趁早。运费折扣交付得越多省得越多，建议中盘前升到 1 级或 2 级。
6. 福缘跟着计划走：要大采购就拿商贾魅力，要爆产能就拿匠人灵感，快撑不住了就拿紧急钱庄保命。

## 🏆 7. 游戏终局与评级

打完整段航程（轻松 8 段、标准 12 段、高难 16 段），每位船长按**声望**拿到最终评级。声望就是历次交付订单净利润的累计。

更长的航程、更高价的货物会带来更多声望，因此三档难度各有自己的门槛。

| 称号            | 轻松声望 | 标准声望 | 高难声望 |
| :-------------- | :------- | :------- | :------- |
| 👑 丝绸之路霸主 | ≥ 1200   | ≥ 3000   | ≥ 6000   |
| 🏆 海上贸易大亨 | ≥ 800    | ≥ 2000   | ≥ 4000   |
| ⭐ 成功商人     | ≥ 600    | ≥ 1500   | ≥ 3000   |
| 👍 合格商人     | ≥ 400    | ≥ 1000   | ≥ 2000   |
| 🌊 新手商人     | < 400    | < 1000   | < 2000   |

## 🛡️ 8. 故障排除

- **「端口 8080 被占用」**：有别的程序占着这个端口。关掉它，或者用 `PORT=8090 python server.py` 换一个端口启动。
- **「该账号已在其他设备登录」**：一个账号同时只能有一条连接，先把另一个标签页或设备关掉。
- **按钮点了没反应**：十有八九是在等其他船长确认。看看底部的「全员就绪 n / N」，再用 💬 催一催。
- **有船长掉线了**：会话在服务器上好好的，对方重新登录就行。聊天和交易会等到那时候再恢复。
- **服务器重启了**：账号还在 `users.json` 里，但进行中的航程存在内存里，没了就是没了，重新开一局吧。
- **跨互联网连不上**：网页和 WebSocket 必须走同一个 https 来源。用一条隧道（`ngrok http 8080`）把这个端口穿出去可以做到，部署到 Railway 也可以，它会给你一个同时提供两者的域名。
- **部署之后账号没了**：托管平台把容器的文件系统清空了。挂一个卷，再把 `USERS_FILE_PATH` 指向卷上的文件，做法见上面的 Railway 一节。

## 🌟 快速参考

- **启动**：运行 `python server.py`，浏览器打开 `http://localhost:8080`
- **放到线上**：今晚就想玩用 `ngrok http 8080`；想让它一直在线，就用附带的 `railway.json` 部署到 Railway

- **破产警告**：结算时金币不够付工资和维护费，这局就出局了（不过还能观战！）
